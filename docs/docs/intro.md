# Eggy

Eggy is a game engine for Zig 0.16. Your game is a Zig package that builds into a runtime
for players and a desktop editor for making the game. Both run the same game and plugins.

## Choose what you need

| You want to | Section | Start with |
| --- | --- | --- |

| Complete a specific task | [How-to guides](/how-to) | [Set up a project](how-to/set-up-project.md), [map controls](how-to/map-input.md), or [distribute a game](how-to/build-and-export.md) |

[Feature support and migration](reference/feature-support.md) to check which services
