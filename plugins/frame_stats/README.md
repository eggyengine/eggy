# Frame Stats

See how fast your game runs while you play it. A small card in a corner of the game shows:

- frames per second,
- the average frame time over the last second,
- the slowest frame of the last second, which shows hitches the average hides.

Press **F3** to show or hide it.

## Preferences

Set these in **Edit > Preferences** under Frame Stats:

- **Corner**: which corner of the game's window the card sits in.
- **Show at start**: whether the card is showing when the game starts.

Frame Stats ships with your game, so players can press F3 too. If you only want it while you
work on the game, remove it before you export.
