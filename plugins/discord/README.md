# Discord

Show what you're working on as your Discord status. While the editor is open, your profile
says you're playing Eggy, with:

- the project you're editing, or playtesting when the game runs,
- the scene you have open,
- how long the editor has been open.

Others see an **Eggy on GitHub** button on it too. Discord has to be running on the same
computer; open it at any time and the status appears within a few seconds.

## Preferences

Set these in **Edit > Settings** under Discord:

- **Application ID**: your own app's ID from the Discord Developer Portal, to show its name
  instead of Eggy's. Leave it at 0 to show Eggy.
- **Show scene**: whether your status names the open scene.

## Dev plugin

Discord only runs in the editor: exported games leave it out.
